# 渲染量化与资产流水线

## 让图标亮度对齐放置态

- **适用条件** 当你需要让物品图标接近对应方块的放置效果时。
- **观察到的现象** 你可能看到换用另一种物品渲染路径后，图标略微变亮，放置态和图标的亮度差仍然明显。
- **判断依据** 你需要掌握改前、改后与参照的亮度差。固定光照、视角和显示条件，对各帧上同一材质表面的可比区域取样。
- **做法** 你可以先定参照和可接受差值，再比较实际图标与对应放置态。若常规渲染路径的采光始终偏离目标，就在当前加载器支持的物品渲染入口核对光照参数、法线和材质后重测。
- **反例/坑** 你若只比较两种图标的相对提升，可能把微小涨幅误判为达标。放置态取样也应避开高光、缝隙与阴影边界。

## 找出光晕越格的绘制层

- **适用条件** 当你在快捷栏、背包或创造栏看到邻格被物品特效压暗时。
- **观察到的现象** 你可能看到邻格暗化随特效几何缩小而消失。只降低不透明度时，本格边缘的特效也可能一起变弱。
- **判断依据** 你需要把四边外扩后的几何宽度换算成 GUI 逻辑尺寸，对照真实槽距。若两个渲染入口共用光晕底板，后续遮罩通常只约束自己的绘制层。
- **做法** 你可以用同一物品、同一邻格和空槽控制帧，分别改尺寸与透明度。固定条件采集多帧，记录越界距离、变暗像素数和本格边缘，再决定改模型参数、遮罩还是公共绘制路径。
- **反例/坑** 你若只换着色器，可能保留同一张越界底板。拿另一种贴图测出来的安全尺寸也无法直接套给当前模型。

## 对齐编辑真源、导出与游戏画面

- **适用条件** 当你调整像素图、骨骼动画、图集采样或可旋转结构时。
- **观察到的现象** 你可能看到编辑器里接触点正确，游戏中却偏转，或首次加载正常、资源重载后取到了别的图块。
- **判断依据** 你要区分导出坐标系、图集代次、骨骼层级和触发动画的实际动作。结构旋转同时影响空间体积、方块方向和功能锚点。
- **做法** 你可以从真源重导出，核对游戏实际加载的资源。分别验证旋转方向、接触点、空格与锚点。缓存 UV 或模型引用时，绑定资源重载生命周期并复查重载后的画面。
- **反例/坑** 你若只看编辑器预览，无法发现运行时图集和业务动作的差异。只旋转几何也会留下原方向或旧锚点。
